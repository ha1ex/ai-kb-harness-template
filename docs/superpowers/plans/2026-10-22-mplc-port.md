# Перенос общих улучшений MPLC — план

**Цель:** выпустить 0.8.0 с каталогом, экспортом документов и методологиями.
**Архитектура:** файловые реестры и frontmatter проекта; единый каталог для dev и static; чистые общие функции контрактов.
**Стек:** Node.js 20/22, React 19, Vite, TypeScript, headless Chromium.
**Основание:** `docs/superpowers/specs/2026-10-22-mplc-port.md`.

## Общие ограничения

Произвольный `KB_ROOT`; слои и категории проекта; нет данных MPLC; обратная совместимость; PDF без минимального числа страниц.

## Особое внимание при ревью

Утечка непубликуемых файлов; обход путей и symlink; архивные ссылки на действующий PDF; глубокие связи parent; утрата контекста при возврате.
