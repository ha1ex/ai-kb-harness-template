# Выпуск 0.8.1 — учебный пример не стареет как рабочий вывод

## Главное

Исправлена остановка CI из-за возраста синтетического walkthrough. Его дата остаётся исходной; явно исключается только проверка возраста этого файла. Свежесть рабочих материалов проверяется по прежним правилам.

Поле `doctor.excludePaths` в `kb.config.mjs` содержит точные пути. Оно не отключает метаданные, ссылки, происхождение утверждений и другие проверки. В шаблоне указан только `04_synthesis/walkthrough-pilot-hypotheses.md`.

`pnpm check` теперь включает `kb-doctor`, чтобы проблема состояния базы обнаруживалась до отправки изменений в GitHub.

## Обновление

Выполните предварительный просмотр `pnpm kb:update --ref v0.8.1`, затем тот же вызов с `--apply`. После установки зависимостей запустите проверки проекта.

Настройки проекта сохраняются. Если вы оставили учебный walkthrough после инициализации, добавьте его точный путь в `doctor.excludePaths`. Исключение подходит для синтетического примера. Для рабочего вывода пересмотрите содержание и основания.

Документы, канвас и методологии из 0.8.0 остаются без изменений. Их состав и проверка описаны в [выпуске 0.8.0](./0.8.0.md).
