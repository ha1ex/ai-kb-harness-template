# Проверки выпуска 0.4.0

Дата: 6 сентября 2026 года. Выпуск переносит общие принципы витрины и работы с агентами в переиспользуемый шаблон. Проектные материалы MPLC не входят в перенос.

## Что проверено

| Область | Проверка |
|---|---|
| Установка | Установка трёх частей через `pnpm run setup`; инициализация полной копии шаблона с независимой Git-историей |
| Агенты | Настройка всех пяти вариантов клиента на настоящих файлах шаблона; сохранность чужих настроек; повторная настройка; старые плоские навыки и новые SKILL.md |
| Передача работы | Сохранение задачи, критерии завершения, передача владельца, восстановление контекста и устаревшего lock после сбоя |
| Обновления | Предварительный просмотр без записи; добавление и удаление; поля package.json; конфликты; частичное применение; явное разрешение; повторный запуск; принятие известной старой базы |
| Сохранность | Инициализация сохраняет изменённые демо-файлы, индекс и настройки клиента; обновление защищает контент и не следует по симлинкам |
| Витрина | Тесты каталога и компонентов; производственная сборка; прямые URL на обычном статическом сервере; переход к источнику и назад |
| Экран | Светлая и тёмная темы при ширине 320, 768 и 1440 пикселей; отсутствие горизонтального переполнения и ошибок браузера в проверенных сценариях |
| Разметка | Тематические стартовые ссылки, состояние GFM-флажков, сохранность исходного кода при преобразовании ссылок на источники |
| Поиск | 48 эталонных запросов: recall@3 = 1, recall@5 = 1, MRR = 0.9549; разница с прежним baseline равна нулю |
| MCP | Настоящий stdio handshake, схемы шести инструментов, поиск, формальная проверка цитаты и сборка запроса с общими правилами |
| Общие проверки | Проверки слоёв, ссылок, происхождения выводов, переносимости и читаемости; прежние тесты retrieval/control/gate |

Проверки обновлений используют временные репозитории с независимой историей. Проверки моделей используют локальный HTTP-сервер и CLI-заглушки: проверяются тайм-ауты, ошибки и предел повторов, внешние модели не вызываются.

## Практические границы

Живые сеансы Codex, Claude, Gemini и GLM не проверялись. Для них подготовлены шесть [общих контрольных сценариев](../../harness/evals/README.md) с отдельной формой оценки; наличие сценария не означает выполненный прогон. Подтверждена настройка общего контекста и инструментов, а не одинаковое качество ответов разных моделей. Отдельная матрица — [совместимость](../compatibility.md).

Статическая витрина включает выбранный корпус в сборку и использует локальный текстовый поиск. Смысловой поиск, граф и SkillOpt используют сервер разработки и соответствующие данные. Изображения внутри документов представлены alt-текстом; исполнение Mermaid и публикация бинарных вложений не входят в этот выпуск.

Формальная проверка источника подтверждает ссылку и допустимость слоя. Она не доказывает истинность вывода. На демонстрационном корпусе остаются семь ранее существовавших предупреждений о справочных заглушках; после удаления демо они отсутствуют.

## Повторить локально

```bash
pnpm run setup
pnpm test
pnpm check
pnpm viewer:test
pnpm viewer:build
pnpm kb:index
pnpm kb:eval
pnpm kb:release:check
```

Последняя команда предназначена для исходного репозитория шаблона. Для нового проекта используйте [быстрый старт](../../README.md#начать-проект); для существующего — [порядок обновления](../upgrades.md).
