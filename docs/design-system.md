# Общие компоненты сохраняют цельность витрины

## Главное

Новый экран продолжает существующие цвета, отступы, кнопки, навигацию и состояния. Общий паттерн меняется вместе со своими потребителями и документацией.

## Источники оформления

- `tools/viewer/src/styles/globals.css` хранит токены темы.
- `tools/viewer/src/styles/workspace.css` задаёт рабочую поверхность, карточки, навигацию и печать страницы.
- `tools/viewer/src/v2/components/ui` хранит кнопки, ввод, вкладки и другие общие элементы.
- `tools/viewer/src/v2/components/MarkdownDoc.tsx` одинаково разбирает Markdown для чтения и экспорта.
- `tools/viewer/print.css` задаёт самостоятельный документ A4.
- `tools/viewer/src/components/MapCanvas.tsx` даёт общий канвас; схема хранит данные в реестре, без предметных условий в компоненте.

Название и акцент берутся из настроек проекта. Частные фирменные цвета исходного проекта в шаблон не переносятся. Изменение печатного оформления делает сохранённые экспорты устаревшими; их нужно пересобрать.

## Каждый экран показывает назначение и состояние

Первый экран объясняет пользу раздела и следующий шаг. Загрузка, отсутствие материалов и ошибка имеют разные тексты. Пустое значение не подменяется нулём. Готовый PDF и печать браузером называются разными действиями.

Один визуальный блок передаёт один вывод. Сначала используйте существующие компоненты. Общий компонент выделяется, когда одна задача повторяется на нескольких экранах.

## Проверка охватывает узкий экран и клавиатуру

На ширине 320 пикселей у страницы нет горизонтальной прокрутки. Широкие таблицы прокручиваются внутри блока. Кнопки и ссылки действия имеют высоту от 44 пикселей. Фокус виден, заголовки последовательны, интерактивные элементы доступны с клавиатуры.

Раскрытие ветки и переход по ссылке остаются разными действиями. Активный путь виден. Фильтры каталога хранятся в URL; возврат сохраняет выбранное состояние. Светлая и тёмная темы передают одинаковый смысл, а уменьшение движения отключает необязательную анимацию.
