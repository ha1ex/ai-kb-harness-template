# Метод выбирается по вопросу

## Главное

Раздел `/methods` показывает, какой подход подходит к задаче, где прочитать карточку и на каких условиях использовать первоисточник. Правила метода помогают рассуждать; факты проекта подтверждаются собственными источниками базы.

## Реестры принадлежат проекту

Пути задаются в `kb.config.mjs` через `viewer.registries.methods` и `viewer.registries.research`. По умолчанию используются файлы `_registry.json` в `06_outputs/methods` и `06_outputs/research`. Их отсутствие даёт пустой раздел.

У реестра методов массив `methods`. Каждая запись содержит уникальный `id`, `title`, `lens`, опубликованный путь `card`, внешний `source` с HTTP(S) и `license`. Необязательны `question` и закреплённая `revision`.

Карточка объясняет назначение, ограничения, порядок работы и форму результата. Агент читает её до вывода. Название известной методологии само по себе не заменяет чтение выбранной редакции. Чужие каноны подключаются по ссылке или отдельной синхронизацией с соблюдением лицензии. Шаблон не поставляет их копии.

У реестра исследований массив `research`. Каждая запись содержит `id`, `title`, массив опубликованных путей `results`; необязательны `question`, `status`, `workdir`. Раздел `/research/<id>` собирает результаты темы. Папка `workdir` исключается из витрины и статического поиска. Состояния и бюджет исследования по-прежнему ведёт рабочая система из `docs/research.md`.

Один итог входит в одну тему. Пустой реестр не создаёт примеров реальной работы. Учебная карточка метода помечена явно и удаляется при `kb:init --strip-demo`.

## Следующая сессия использует сохранённый результат

Агент начинает с `pnpm kb:context --task <id>`, открывает актуальные основания и продолжает с незавершённого шага. Успешную проверку повторяют при изменении входов, ошибке или новом конкретном риске. Свежесть экспортов проверяется по содержимому, а не по дате запуска.

Долгая задача сохраняет промежуточный результат и фактические проверки через `pnpm kb:session`. Независимое ревью выполняется в отдельном контексте и не заменяется отметкой автора о собственной проверке. Модель и клиент выбираются пользователем; общий процесс не требует конкретного провайдера.

## Стартовые карточки ведут к канонам

В свежей копии есть маршруты к Next Move Theory, КПО/XPM, Карте гипотез, управленческим playbook, сборке презентаций, правилам нотаций и OODA. У каждой карточки указан первоисточник, автор и условия использования. Редакция закреплена коммитом, где он известен.

Кнопка «Читать канон» открывает первоисточник. Локальная карточка описывает назначение и маршрут. Для локального зеркала проект отдельно сохраняет лицензию, атрибуцию и точную редакцию; текст первоисточника не переписывается. Учебные и стартовые карточки можно удалить через `kb:init --strip-demo` до своей настройки.
