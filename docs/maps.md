# Канвас помогает прочитать схему и проверить её основания

## Главное

Раздел `/maps` собирает схемы проекта. Читатель открывает канвас, ищет блок, меняет масштаб и выбирает связи. Подробности блока ведут к документу базы. Табличная версия доступна с той же страницы.

Свежий шаблон содержит синтетическую схему «От источника к документу». В ней нет данных MPLC.

## Данные задаёт реестр проекта

Путь реестра задаётся полем `viewer.registries.maps` в `kb.config.mjs`. По умолчанию используется `06_outputs/maps/_registry.json`. Объект содержит массив `maps`.

| Поле | Назначение |
|---|---|
| `id`, `title` | Уникальный адрес и заголовок схемы |
| `description` | Что читатель увидит на схеме |
| `source` | Необязательный путь к опубликованному описанию схемы |
| `nodes` | Блоки с `id`, `label`, координатами `x`, `y`; необязательны `summary`, `source` |
| `edges` | Связи с `id`, `from`, `to`; необязательны `label`, `kind` |

Координаты — неотрицательные числа. Идентификаторы блоков и связей уникальны внутри схемы. Концы каждой связи существуют. Каждый `source` открывается в опубликованной базе. Команда `pnpm kb:documents` проверяет эти условия вместе с остальными реестрами.

Канвас не меняет файлы проекта. Положение, текст и связи редактируются в реестре и проходят обычную проверку и публикацию. Предметные модели, юридические схемы и диаграммы конкретного проекта создаются отдельно.

## Как работать со схемой

1. Откройте «Схемы» и выберите карту.
2. Найдите блок по названию или описанию. Нажмите найденный результат: канвас покажет его крупнее.
3. Перетаскивайте фон. Кнопки «Увеличить», «Уменьшить» и «Вписать схему» меняют вид.
4. Выберите блок. Под канвасом появятся описание, связанные блоки и ссылка на источник.
5. В списке «Связи» оставьте нужный вид. Для чтения без графики раскройте «Табличное представление».

На узком экране канвас перемещается внутри рамки и не растягивает страницу. Кнопки доступны с клавиатуры. Блоки можно выбрать клавишами Tab и Enter; таблица сохраняет текст и источники. Для печати раскройте табличное представление или распечатайте исходный документ схемы.
