# Синтетический пример человеческой базы знаний

## Главное

Этот небольшой вымышленный набор показывает путь от наблюдения к сводке и общему выводу. Названия, числа и организация придуманы для демонстрации. Каталог `examples/` не входит в рабочие слои поиска по умолчанию.

Читайте по порядку:

1. [заметки исследования](./02_sources/research-notes.md);
2. [сводка источника](./02_sources/research-summary.md);
3. [синтез решения](./04_synthesis/pilot-recommendation.md).

## Перенести пример в рабочую базу

Копируйте содержимое папок слоя в одноимённые папки корня KB. Не переносите этот README в индексируемый слой.

```bash
cp -R examples/human-kb/02_sources/. 02_sources/
cp -R examples/human-kb/04_synthesis/. 04_synthesis/
```

Внутри документов доказательные ссылки имеют канонический вид `/02_sources/file.md`. Поэтому после такого копирования проверки происхождения и существования источников видят те же пути, что и витрина. Поле `related` остаётся относительным к самому документу и подходит как для просмотра примера здесь, так и после копирования структуры без переименования файлов.
