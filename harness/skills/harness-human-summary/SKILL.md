# harness-human-summary

Read docs/human-interface.md and harness/rules/evidence.md. Lead with purpose, conclusion, status and next step. Preserve uncertainty and source links; do not restyle verbatim quotations. Check the result at narrow and wide widths when it is a visual artifact.


For text longer than one screen, use a separate critic context when available. Give the critic only the draft, its reader and intended action; ask where the text is unclear. The author retains responsibility for facts, numbers, names and sources after rewriting. If independent review is unavailable, name the limitation.

Analytical outputs may use an Executive summary, provenance-preserving footnotes and explicit manual follow-ups. Keep claim labels in the underlying evidence documents; adopting a different publication format does not relax evidence checks. Read `docs/documents.md` for source downloads, editions and export freshness.
