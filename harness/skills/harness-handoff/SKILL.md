# harness-handoff

Read harness/rules/workflow.md. Run scripts/session-start-context.mjs with a task ID. Save a separate owned task record with goal, explicit acceptanceCriteria, confirmed decisions (empty array when none), constraints, sources, changed files, actual checks, open questions and next step. Transfer the writer explicitly when needed.
