# Скиллы Социотеха — исполняемый слой нотаций

## Главное

Исполняемые правила для карт и схем. Канон открывается по ссылке на первоисточник. Локальная копия не включена.

## Когда читать

Как проверить нотацию схемы?

Откройте [закреплённую редакцию канона](https://github.com/Byndyusoft/sociotech-ai-skills/tree/e57047edc305f5e366f0542898defab4cc377fca) и выберите нужные главы до подготовки вывода. Эта карточка задаёт маршрут чтения.

## Как применить к своему проекту

1. Прочитайте назначение и границы подхода в каноне.
2. Выберите форму результата, подходящую к вопросу.
3. Заполните её сведениями из источников своей базы.
4. Отдельно назовите неизвестное и следующий шаг проверки.

Метод задаёт способ рассуждения. Факты проекта, числа, даты и решения берутся из источников проекта. Отсутствующее значение остаётся неизвестным.
