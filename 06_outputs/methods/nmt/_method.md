# Next Move Theory / Advanced JTBD

## Главное

Выбор аудитории, ценности и требований к продукту. Канон открывается по ссылке на первоисточник. Локальная копия не включена.

## Когда читать

Какую работу делает продукт и для кого?

Откройте [закреплённую редакцию канона](https://github.com/zamesin/Next-Move-Theory-Canon-and-Skills/tree/259bc127b2732ca3e19387ea91956c64b3347dc6) и выберите нужные главы до подготовки вывода. Эта карточка задаёт маршрут чтения.

## Как применить к своему проекту

1. Прочитайте назначение и границы подхода в каноне.
2. Выберите форму результата, подходящую к вопросу.
3. Заполните её сведениями из источников своей базы.
4. Отдельно назовите неизвестное и следующий шаг проверки.

Метод задаёт способ рассуждения. Факты проекта, числа, даты и решения берутся из источников проекта. Отсутствующее значение остаётся неизвестным.
