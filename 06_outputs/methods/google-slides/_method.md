# Сборка презентации по шаблону (skill google-slides)

## Главное

Повествование и сборка презентации по образцу. Канон открывается по ссылке на первоисточник. Локальная копия не включена.

## Когда читать

Как показать вывод читателю презентации?

Откройте [закреплённую редакцию канона](https://github.com/openai/plugins/tree/1e285826e604f66f7208f7ac4dba0fe8341d1f57) и выберите нужные главы до подготовки вывода. Эта карточка задаёт маршрут чтения.

## Как применить к своему проекту

1. Прочитайте назначение и границы подхода в каноне.
2. Выберите форму результата, подходящую к вопросу.
3. Заполните её сведениями из источников своей базы.
4. Отдельно назовите неизвестное и следующий шаг проверки.

Метод задаёт способ рассуждения. Факты проекта, числа, даты и решения берутся из источников проекта. Отсутствующее значение остаётся неизвестным.
