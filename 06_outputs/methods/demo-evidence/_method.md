# Учебный метод: проверка основания

## Главное

Метод помогает проверить вывод до его публикации. Это учебная карточка, которую проект заменяет своей методологией.

## Когда использовать

Когда нужно связать результат с источником и показать ограничения читателю.

## Порядок работы

1. Сохраните оригинал и составьте короткое саммари.
2. Разделите содержание источника и свой вывод.
3. Назовите недостающие сведения.
4. Проверьте формулировку по первоисточнику.

## Границы

Метод задаёт вопросы. Ответы о проекте берутся из источников базы. Карточка не подтверждает факты проекта и не считается внешним исследованием.
